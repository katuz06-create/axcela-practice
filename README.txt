AXCELA PRACTICE ENGINE — V0.1 INDEPENDENT PROTOTYPE

This is a NEW, INDEPENDENT project. Do not upload these files to the existing TikTok Content Engine repository or Netlify site.

Files:
- public/index.html    Standalone prototype UI
- netlify.toml         Netlify publish folder settings

CURRENT FUNCTIONALITY
- Personalization: optional website, job function, speaking situation, CEFR, 1–5 learning points.
- 5-part journey preview, 10-session structure shown.
- Part 1 / Session 1: interactive 5-question sample diagnostic, answers, explanations, sample mastery.
- Browser-local demo progress only. No account data store.

NOT YET IMPLEMENTED
- Fetch / analysis of company website.
- Dynamic AI-generated exercises matched to company / learning points.
- Real 4 x 5 exercises per session; remaining 9 sessions.
- Parts 2–5, audio recording, pronunciation assessment, full scoring and unlock logic.
These parts are deliberately labeled and locked. No fabricated AI scores.

DEPLOY TO A NEW REPOSITORY
1. Create a NEW GitHub repository: axcela-practice-engine (do NOT touch Axcela-Tiktok-Content-).
2. Add public/index.html and netlify.toml preserving the directory structure.
3. In Netlify, choose Add new project > Import an existing project > GitHub > axcela-practice-engine.
4. Publish directory is public. No build command needed. Use a NEW Netlify site.
5. Open the new URL. The existing TikTok platform is unchanged.

SECURITY: No API keys are required for V0.1. No external requests, no real AI processing.
